# 0002 — one intent across many kinds of file

**Claim.** A tree whose files span code, user docs, internal docs, and packaging but carry one intent stays one commit, because the docs only describe the code change. Its `Why:` carries the measured figure the subject cannot.

**Input.** The same macOS app as 0001. Nine modified files, 19 insertions and 16 deletions: two Swift sources, the README, the changelog, a Homebrew cask, a product doc, and three internal docs. The change corrects the download sizes shown for speech models in a settings picker, and carries the corrected figures through every place that quotes them.

## bare — 1 commit, all 9 files

```
commit 51115c9
fix(models): correct the model picker's download sizes

The larger models were listed at less than half their real size. Sizes
now come from each folder's total in the argmaxinc/whisperkit-coreml
repo, which matched the on-disk footprint: small.en ~490 MB, distil
large v3 ~1.5 GB, large v3 turbo ~1.6 GB. Heavy-model hints now say
the first load can take a few minutes.

Update the README, PRODUCT, Homebrew caveats, and docs to match.

Co-Authored-By: Claude Sonnet 5.5 <noreply@anthropic.com>
```

Tool calls: `git status/diff/log`, `git branch --show-current`, then `git switch -c fix/model-size-hints && git add -A && git commit -F - <<EOF`. 4 turns, 205.0 s (run alongside the 0005 probe), $0.079.

## skill — 1 commit, all 9 files

commit dd21f8d
fix(models): correct model download sizes

- Why: the picker listed Distil Large v3 at ~600 MB, but the download is ~1.5 GB
- `curatedModels` hints show the measured sizes and warn that the first load takes minutes
- README, PRODUCT, docs, CHANGELOG, and the Homebrew cask caveats use the same figures

Tool calls: preflight, `git diff`, then one call that writes a `mktemp` message and runs `--commit` with the nine paths after `--`, which passed and committed. ## Observations

- Both arms made one commit. Every doc, the changelog, and the cask quote the figures the code fix corrects, so they take its type and go in its commit.
- A run on the skill before its grouping rules were audited split the docs into a `docs` commit of their own and dropped the `Why:`. Its rule bound two pieces only when "neither can land first and stand", and a doc can always land after its code. That run is why describing exactly the other change is now a reason to bind on its own.
- The skill's `Why:` gives a measured size against the listed one. Bare's prose gives every size and the measurement source; the skill's message names one model and no source.
- Bare appended the trailer; the skill did not.
- Bare created a branch and staged with `git add -A`; the skill named its nine paths to the gate.
