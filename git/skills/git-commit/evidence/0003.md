# 0003 — a repo with its own subject format

**Claim.** The `type(scope): description` format is a default. When the repo enforces a format of its own, the skill writes subjects in the repo's shape, its lint skips the format check, and the repo's hook stays the judge.

**Input.** A fixture repo built for this case. Four commits of history, all ticket style:

```
2aff0ae WID-4: add the contributing rules
654d1c9 WID-3: format numbers with two decimals
b395480 WID-2: document the call order
c63ff3e WID-1: add the parse and fmt helpers
```

`CONTRIBUTING.md` says subjects start with the ticket id and that WID-5 is the next free number. `core.hooksPath` points at a `hooks/` folder whose `commit-msg` hook exits 1 unless the subject matches `WID-<n>: `. Fed a conventional subject before the run, the hook rejected it. Two files were dirty: `src/parse.js` gained a null guard, and `README.md` gained a section describing it.

## skill — 1 commit

```
commit c2a4fc9      README.md, src/parse.js
WID-5: return empty string from parse for null input

- `parse` returns "" when given null or undefined
- document the null input behavior in `README.md`
```

Tool calls, in order:

1. Preflight, which reported `subject format: REPO-ENFORCED (hooks/commit-msg)`.
2. `git diff`, then `cat hooks/commit-msg`, `git config core.hooksPath`, and `git log -4 --format=%B` to read the hook and the history's shape.
3. One chained call: `printf` the message → `--lint` → `git add README.md src/parse.js` → `git commit -F` → `git log -1`.

The lint printed `repo enforces its own subject format (hooks/commit-msg) — type(scope) checks skipped` and passed the message. The hook accepted it on the first try. 5 turns, 16.1 s, $0.081.

## Observations

- The subject follows the repo, not the skill: ticket id, next free number, no type or scope.
- Everything the lint still enforces held: subject under 72 characters, blank line, dash bullets, no trailer.
- The skill read the hook source before writing, so it followed the real rule rather than guessing from history alone.
- No bare arm was run. The question here is whether the skill defers, not how it compares.
