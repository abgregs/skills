# 0001 — a single-intent tree

**Claim.** The skill does not split a tree that carries one intent, and its docs go with it. Its body is dash bullets that name the code that acts, led by a `Why:` bullet when the change has a cause from outside the code, and never carries a provenance trailer.

**Input.** A macOS app in Swift. Eight modified files, 169 insertions and 142 deletions: a tap state machine, the hotkey manager that drives it, the session object, their three test files, the changelog, and one architecture doc. The change moves "is a recording live" out of the state machine and into the session, so a start the session refuses no longer leaves the next tap misread as a stop. The repo's own `docs/conventions/git.md`, linked from its `AGENTS.md`, asks for conventional subjects, dash bullets, and a `**Why:**` line on commits with a non-obvious tradeoff.

## Observations

- Both arms kept the eight files as one commit and chose the same type and scope. The changelog and the architecture doc describe the fix, so they went in its commit.
- All four skill runs lead with a `Why:` naming the trigger: a start the session refused while the model prepared, a permission was missing, or a dictation was transcribing. Bare's bullets say a refused start no longer swallows the next tap, and name no trigger.
- Every bullet in the four committed messages has the code that acts as its subject. On the skill before the code-as-subject rule, all four runs committed `` `HotkeyManager.isRecording` is set by `RiverSession` ``. Here three of four first drafts still used a passive verb, and the lint's warning stopped each; every rewrite named the code that acts, as in r3's `` `RiverSession` sets `HotkeyManager.isRecording` from `currentState` ``. In this case the warning, more than the wording, holds the form.
- Every committed body has six bullets, the most the skill allows, and two first drafts had seven, which the lint failed. On the skill before, whose rule read 1–4 bullets, these runs wrote four or five. A removal named through its owner takes a bullet of its own, where a passive clause had folded two removals into one.
- Bare appended the trailer the harness asks for; no skill run did.
- Bare staged with `git add -A`. Every skill run named its eight paths to the gate and staged nothing by hand.
