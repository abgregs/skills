# 0001 — a large corpus with two rules in tension

**Claim.** On a corpus big enough that the old scout's report ran to 88 KB, the agent reads the digest in one call without piping it, reads the shortlisted docs in full, cites each rule on the line it sits, carries each **Why:** forward, names the tension between two rules, and asks what blocks the plan before writing any code.

**Input.** `bash fixtures.sh 0001 <dir>`: a small Node API, `shelf`, with a `docs/` tree in the contract's shape. Four real docs carry the rules; a generated `docs/reference/` holds 600 table docs in 30 indexed folders, so most of the corpus is noise. The two rules in tension:

`docs/conventions/caching.md:5`

```
- Cache list endpoints per user for 10 minutes, keyed by `user:<id>:<route>`.
```

`docs/architecture/data-lifecycle.md:3`

```
- Account deletion removes every copy of a user's data within 5 minutes, caches included.
```

The convention also requires a shared `src/cache.js` that does not exist. On this repo the scout before this version printed 88,013 bytes for the task's words; the current one prints 7,812.

**Prompt.** `/eval:brief Add per-user caching to GET /lists so repeat loads are fast.`

**Result.** Batch 6:

- One scout call, unpiped: a 7.8 KB digest, not cut, with `docs/conventions/caching.md` and `docs/architecture/data-lifecycle.md` on the shortlist.
- Nine files read with `Read`: five docs (`caching.md`, `data-lifecycle.md`, `reading-lists.md`, `api-endpoints.md`, `roadmap.md`), `docs/_index.md`, `CLAUDE.md`, the route, and `src/db.js`.
- 12 `file:line` citations, ten in `docs/` and two in `CLAUDE.md`, each on the line it quotes, with every **Why:** quoted from its source; one question names `caching.md`'s **Why:** by its line, 9.
- The tension named before the plan: a 10-minute cache entry outlives the 5-minute deletion promise, so deletion has to purge the user's keys.
- Two questions before the plan, each with a recommended answer: what store backs the missing `src/cache.js`, and whether writes invalidate the key. The draft plan waits on them.
- `git status` clean after the run: no code and no doc written.
- 12 turns, $0.12.

Batches 3 and 4, on earlier skill states, gave the same shape: one unpiped call of 7.8 KB, 11 citations on their lines, both rules of the tension cited, and the plan held on the cache store.
