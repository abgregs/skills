# 0001 — a large corpus with two rules in tension

**Claim.** On a corpus big enough that the old scout's report ran to 88 KB, the agent reads the digest in one call without piping it, reads the shortlisted docs in full, cites each rule on the line it sits, carries each **Why:** forward, names the tension between two rules, and asks what blocks the plan before writing any code.

**Input.** `bash fixtures.sh 0001 <dir>`: a small Node API, `shelf`, with a `docs/` tree in the contract's shape. Four real docs carry the rules; a generated `docs/reference/` holds 600 table docs in 30 indexed folders, so most of the corpus is noise. Fifteen of those tables carry `user_id`, `list_id`, and `cache_version` and mention repeat loads, as a real generated schema would, so the noise shares the task's common words; ranked by count alone, those tables filled the shortlist and left out `caching.md`. The two rules in tension:

`docs/conventions/caching.md:5`

```
- Cache list endpoints per user for 10 minutes, keyed by `user:<id>:<route>`.
```

`docs/architecture/data-lifecycle.md:3`

```
- Account deletion removes every copy of a user's data within 5 minutes, caches included.
```

The convention also requires a shared `src/cache.js` that does not exist. On this repo the scout before this version printed 88,013 bytes for the task's words; the current one prints 7,812.

**Prompt.** `/eval:brief Add per-user caching to GET /lists so repeat loads are fast.`

**Result.** Batch 10, three runs, on Opus:

| | Run 1 | Run 2 | Run 3 |
|---|---|---|---|
| Scout call | one, unpiped, terms `caching cache lists user repeat loads` | the same | the same |
| Digest | 11.1 KB, not cut | the same | the same |
| Shortlist | `caching.md` on it; `data-lifecycle.md` not, its words shared with the noise | the same | the same |
| `data-lifecycle.md` | read, through `caching.md`'s link | the same | the same |
| `file:line` citations | 13, each on its rule's line | 11, each on its line | 12, each on its line |
| The tension | named before the plan: the 10-minute cache outlives the 5-minute deletion promise | named | named |
| `git status` | clean | clean | clean |
| Turns, cost | 14, $0.26 | 11, $0.25 | 8, $0.23 |

Batch 6, on Sonnet and the fixture before the noise, had `data-lifecycle.md` on the shortlist; with the noise it reaches the run only by Step 1.4's cross-references, which every run followed. Batch 8 gave the same result in two runs.
