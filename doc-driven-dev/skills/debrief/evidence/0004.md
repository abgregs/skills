**Claim.** With no mark, no commits past the branch point, and a clean tree, `--scope` refuses to guess a base (exit 4) and lists the recent commits, and the agent stops for a range instead of taking the last five commits unseen.

**Input.** `bash fixtures.sh 0004 <dir>` builds `ledger` as in 0003, up to checking out `feat/cents`: one commit storing money as float dollars, six release-note commits, a branch with no commits and nothing uncommitted. Before this version the sweep took `HEAD~5` here without comment. The arm runs in `ledger`.

**Prompt.** `/eval:debrief The user is away for this run: treat every doc update you recommend as approved, and take your recommended option wherever you would ask a question.`

**Result.** Batch 7, two runs, the same in both:

- One `--scope` call, exit 4: "no reliable base … ask the user which range to review".
- Then a stop: no sweep, no edit, no mark, `git status` clean.
- The summary says why it stopped and offers a range to rerun with, named as a candidate, not taken: "To go on, tell me the range, for example `--scope --base 606ee9a`". Run 2 added that the standing approval did not cover this: "the choice is which commits count as 'the task', and I can't recommend one from the repo alone."
- 2 turns, $0.07 each.

Batch 5 read the standing approval as covering the range: it chose `--base fa12c52` itself, named it, and committed cross-links no change asked for. Batches 6 and 7 stopped, as Step 1 says to with no user to ask.
