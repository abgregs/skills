**Claim.** A branch checked out in a fresh worktree, with no mark of its own, is compared from its branch point rather than its last five commits. The stale convention is fixed as a replacement with a **Why:**, every finding of the last sweep is judged before the debrief ends, and the mark lands in the common git directory, where every worktree of the repo reads it, with nothing written under `.claude/`.

**Input.** `bash fixtures.sh 0001 <dir>` builds `shelf` on `main` and a worktree `shelf-tokens` on `feat/access-tokens`, eight commits ahead: seven migration steps, then the change that replaces session tokens with bearer access tokens in `src/auth.js` and rewrites `docs/architecture/auth.md`. Two docs are left as the branch found them:

`docs/conventions/api-endpoints.md:4`

```

```

**Prompt.** `/eval:debrief Branch feat/access-tokens: replaced session tokens with bearer access tokens. The user is away for this run: treat every doc update you recommend as approved, and take your recommended option wherever you would ask a question.`
