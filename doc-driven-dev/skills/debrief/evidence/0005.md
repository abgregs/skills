# 0005 — a change to code alone

**Claim.** When the change edits code and no doc, the stale docs are still found: by Step 2's reads, and by the sweep through the names the code dropped.

**Input.** `bash fixtures.sh 0005 <dir>` builds 0001's repo, except that the branch's last commit changes `src/auth.js` only: `docs/architecture/auth.md` still describes the 30-day session token, and `docs/conventions/api-endpoints.md:4` still requires `X-Session`. No doc line changes since the branch point. Before the sweep took terms from the code diff, its dry run showed "0 retired-term, 0 referrer, 0 freshness, 0 structure"; it now raises `x-session`, from the code diff, with a hit on each stale doc. The arm runs in `shelf-tokens`.

**Prompt.** `/eval:debrief The user is away for this run: treat every doc update you recommend as approved, and take your recommended option wherever you would ask a question.`

**Result.** Batch 10, three runs, on Opus:

| | Run 1 | Run 2 | Run 3 |
|---|---|---|---|
| `--scope` base | the merge-base with `main` | the same | the same |
| Both stale docs fixed | `api-endpoints.md:4` and `auth.md` | the same | the same |
| Verdict check | all 8 findings judged | all 6 judged | all 8 judged |
| Commit, then `--mark` | `docs(auth): document bearer access tokens in place of X-Session` | `docs(auth): describe bearer access tokens, index planning/` | `docs(auth): document bearer access tokens, index planning/` |
| Turns, cost | 22, $0.45 | 25, $0.46 | 27, $0.49 |

Every run found both stale docs from the diff and its reads and fixed them before its first sweep, so the `x-session` term the code diff gives, which the fixture's dry run shows on both docs, was not needed. Each **Why:** reads `reason not recorded`: the commit says what changed, not why. Run 3's new-claim check caught its own draft saying `/login` issues the token, when no `/login` code exists; it became an open item.

Before the sweep took terms from the code diff, its dry run of this case showed no finding at all.
