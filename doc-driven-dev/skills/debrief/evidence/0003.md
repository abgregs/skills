# 0003 — uncommitted work on a branch with no commits

**Claim.** On a branch with no commits of its own, where the whole change is still uncommitted (a staged code edit, an unstaged doc edit, and a new file not yet added), `--scope` takes HEAD as the base rather than the last five commits of `main`, and lists the untracked file; the agent reads that file and fixes the stale convention with a **Why:** drawn from it.

**Input.** `bash fixtures.sh 0003 <dir>` builds `ledger`: one commit storing money as float dollars, six unrelated release-note commits on `main`, then `feat/cents` checked out with no commits. The change is in the working tree only:

```
 M docs/architecture/entries.md     the column renamed to `amount_cents` (unstaged)
M  src/ledger.js                    amounts stored through `toCents` (staged)
?? src/currency.js                  the new rule and its reason, in a comment
```

`docs/conventions/money.md` still says "Store every amount in `amount_dollars`, a float." The reason for the change, float drift with "a month of 0.10 entries summed to 2.9999999999999996", appears only in the untracked `src/currency.js`. Before this version the base would have been `HEAD~5`, five release-note commits; the fixture's dry run showed `--scope` printing HEAD, the two changed files, and `src/currency.js` under "UNTRACKED FILES (1): not in git diff; Read each one". The arm runs in `ledger`.

**Prompt.** `/eval:debrief I switched money amounts from float dollars to integer cents; none of it is committed yet. The user is away for this run: treat every doc update you recommend as approved, and take your recommended option wherever you would ask a question.`

**Result.** Batch 7, two runs:

| | Run 1 | Run 2 |
|---|---|---|
| `--scope` base | HEAD, "only uncommitted changes are reviewed" | the same |
| Untracked file read | `src/currency.js`, in the same call as `git diff <base>` | the same |
| First sweep | `T-da0a` (`amount_dollars`), `T-feed` (`dollars`), `R-cced` (the architecture index) | the same three |
| Re-sweep after the fixes | no findings | no findings |
| Detector calls piped | none | none |
| `--verdicts -` | `nothing to judge (exit 0)` | `nothing to judge (exit 0)` |
| Commit | none | none |
| `--mark` | at HEAD | at HEAD |
| Turns, cost | 14, $0.16 | 11, $0.14 |

`money.md` now stores `amount_cents` as an integer through `toCents`. Its **Why:** quotes the float drift from `src/currency.js`, "a month of 0.10 entries summed to 2.9999999999999996", which no other file holds; run 1 added a second **Why:** for moving the rounding, with `reason not recorded` beyond that drift. Both linked `money.md` and `entries.md`, updated the index summaries, and set the money axis's `last audited:` date.

Both left the doc fixes uncommitted beside the uncommitted code, marked at HEAD, and said so: "I haven't committed anything, because the code the docs describe is also uncommitted. The debrief mark is set at HEAD (`1e93748`), so these changes will show up again in the next debrief." That is what Step 6 now says for this case. Batch 5 left the fixes in the same place but did not mark.
